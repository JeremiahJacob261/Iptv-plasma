Current public origin: https://free-iptv-player-sigma.vercel.app
Planned domain: plasmax.io. The domain is not purchased or attached. All internal links remain relative; the site does not redirect visitors to the planned domain.

The static build runs scripts/brand-pages.mjs after all page generators, applying the PlasmaX logo, favicon, titles, homepage entry links and player branding. Original stylesheet files, UI structure and type sizes are retained. A colour-only theme.css layer generated by scripts/theme-pages.mjs uses the supplied logo’s purple and accessible lavender links. SVG logo lockups embed the supplied crescent/flame artwork after transparent-background preparation; the original is preserved in icons/plasmax-supplied-logo.jpg; the promotional PNG is an actual screenshot of our player with clearly illustrative News/Entertainment/Kids rows, not evidence of live playback. Asset provenance is in icons/PlasmaX-PROVENANCE.json and the PNG's text metadata.

## Advertising
Advertising is disabled and makes no network request until configured. The named Advertisement slot on the player pages stays hidden while disabled. It sits outside the video and controls.

For Google AdSense, use an approved publisher's own display unit from https://support.google.com/adsense/answer/9190028 : set advertising.enabled=true, provider=adsense, publisherId to the real ca-pub-… identifier and slotId to its real data-ad-slot. The build generates ads.txt for that configured publisher. Invalid or missing identifiers keep ads off; no sample credentials ship in production config. The script loads asynchronously near the placement. Provider approval, site verification, consent requirements and account configuration are not established by inserting code.

HilltopAds requires the actual account-specific approved snippet; it has not been connected. Do not substitute an invented script URL or publisher ID.

## Video watermark
brand.js wraps newly created IPTV videos and brands existing social media frames without replacing the video, changing its source or blocking controls. The custom Full screen button targets the branded wrapper when the browser supports element fullscreen. Native iOS video fullscreen and native video control fullscreen can leave the DOM wrapper, so the page watermark cannot be guaranteed in those modes; it is a UI overlay, not burned into broadcaster video.

## Hilltop Ads — configured 2026-11-01
The user selected Hilltop and supplied a banner script, a popunder URL, and a direct sponsor URL. data/site-config.json enables Hilltop. dist/hilltop.js loads one labelled banner placement on the home, IPTV, X and Twitch pages only when near the viewport; the direct link is labelled Visit sponsor and uses rel=sponsored/noopener/noreferrer. The popunder is attempted on an eligible trusted background click at most once per 24 hours per browser using localStorage; controls, links, form elements, video and ad placement are excluded. Popup blockers, cleared browser storage, different devices, and the ad provider's own code affect actual behaviour. The app's cap does not control any separate popups created by third-party scripts. Browser tests mocked the provider, so successful ad fill or revenue is not certified. No Hilltop ads.txt entry was supplied.
